## 6단계. 글로벌 확장

> 원어민 검수 없이 **AI로 현지화**하고, 출시 후 유저 피드백으로 고쳐 나갑니다. 추가 비용 없이 진행합니다.
> 직역이 아니라 **현지 정서에 맞는 카드로 바꾸는 것**이 핵심입니다.

**우선순위**: 영어 → 일본어 → 번체 중국어 (파티게임 수요·결제력 기준)

언어별 체크리스트
- [ ] UI 번역 (`src/locales/{locale}.json`)
- [ ] AI로 카드 현지화 (`src/data/cards/{locale}/`)
  - 요청 예: "한국 밸런스 게임을 영어권에서 인기 있는 주제로 바꿔줘"
- [ ] **AI 2차 검토**: 다른 대화창에서 "원어민 입장에서 어색하거나 문화적으로 민감한 카드 찾아줘"
  - 종교·체형·정치 관련 카드 제외
  - 라이어 단어는 현지에서 누구나 아는 단어인지 확인

  | 현재 카드 | 문제 | 영어권 예시 |
  |---|---|---|
  | 부먹 vs 찍먹 | 문화 맥락 없음 | Pineapple on pizza: yes vs no |
  | 붕어빵 머리 vs 꼬리 | 대상이 생소 | Cereal: milk first vs cereal first |
  | 민초 vs 반민초 | 그대로 통함 | Mint chocolate: love vs hate |

- [ ] 폰트 분기: 본문은 디바이스 기본 폰트라 일본어·중국어도 표시됨. 장식용 폰트(Gowun Dodum 등)만 확인 필요
  - 로케일별 폰트 동적 로드 (Noto Sans JP / Noto Sans TC 등, 무료 라이선스)
- [ ] 장식용 라틴 폰트 확장 서브셋 확인 (악센트 문자)
- [ ] 스토어 메타데이터·스크린샷 언어별 제작 (설명 문구도 AI 작성 + AI 2차 검토)
- [ ] 국가별 가격대 설정 (스토어 가격 등급 활용)

출시 후 무료로 품질 관리하기
- [ ] **카드마다 "이 카드 이상해요" 신고 버튼** → 유저가 검수자 역할
- [ ] 언어별 스토어 리뷰 주기적 확인 → 문제 카드 수정 후 업데이트
- [ ] 해당 언어를 쓰는 지인이 있으면 가볍게 훑어봐 달라고 부탁 (선택)

## 7단계. 수익화 2차

5단계 반응을 본 뒤 순서대로 추가합니다.

| 순서 | 방식 | 내용 | 거부감 |
|---|---|---|---|
| 1 | **평생 이용권** | "MOCA Pro" 일회성 결제로 전부 해금 (5~9천원) | 매우 낮음 |
| 2 | **나만의 덱 만들기** | 사용자가 자기 모임용 질문을 직접 입력 (유료 기능) | 낮음 |
| 3 | **보상형 광고** | 원할 때만 시청 → 테마 24시간 체험 | 낮음 |
| 4 | **B2B 커스텀 덱** | 기업 워크숍 · 교회 · 학원용 맞춤 덱 제작 | 없음 |

### 하지 않을 것

| 방식 | 이유 |
|---|---|
| 전면 · 배너 광고 | 모임 중 광고 노출은 앱 자체를 민망하게 만듦 |
| 월 구독 | 사용 빈도 대비 부담, 구독 피로 |
